Dies sind Dateien von der BlackTea Motorcycles Website, die für Besitzer der Motorräder interessant sein sollten. 

Im Ordner PDF finden sich die PDF Dateien, wie bspw. Kabelbäume, Manuals, usw.

Die Ordner [Wildfire Handbuch_files](https://github.com/lost-hope/BlackTea_files/tree/main/Wildfire%20Handbuch_files) und [Bonfire - Electric Motorcycle manual_files](https://github.com/lost-hope/BlackTea_files/tree/main/Bonfire%20-%20Electric%20Motorcycle%20manual_files) sind die Daten um die website zu rendern. im normalfall braucht man diese nicht. 
die dazu gehörigen HTM Dateien [Wildfire Handbuch.htm](https://github.com/lost-hope/BlackTea_files/blob/main/Wildfire%20Handbuch.htm) und [Bonfire - Electric Motorcycle manual.htm](https://github.com/lost-hope/BlackTea_files/blob/main/Bonfire%20-%20Electric%20Motorcycle%20manual.htm) nutzen diese Dateien. Einfach alles als ZIP runterladen, entpackenund dann kann man mit einem Browser die htm datei öffnen.

Die Datei [Ersatzteile.txt](https://github.com/lost-hope/BlackTea_files/blob/main/Ersatzteile.txt) ist eine Notizdatei von mir für die Bonfire.

Solltet ihr noch dateien haben, die hinzugefügt werden sollen, erstellt ein PR oder kontaktiert mich, sodass ich dies dann hinzufüge
